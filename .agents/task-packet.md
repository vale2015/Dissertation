# Compact specialist task packet

Use fresh context. Aim for at most 500 words of briefing, excluding code or necessary evidence. Fetch other context only when needed.

- Workflow/task ID and exact VS Code project path
- One requested outcome and testable acceptance criteria
- Relevant source commit and current local changes
- Files owned by this specialist, plus essential reference sections
- Selected role/model/effort and delivery path: QUICK, STANDARD or FULL
- Required checks, valid reusable evidence and mutation/approval limits
- Known blocker, next role and stop condition (two unsuccessful fix/retest cycles)

Return a short handoff with changed files, actual checks, remaining risks and next action. Link long evidence instead of repeating logs. The coordinator retains ownership of tracker/Trello/publication and workflow usage. Do not add specialist roles that the task does not need.
