# Frontend implementation

Implement only the approved scope in the existing Next.js app. Preserve the current light dashboard, left navigation, red accents, and left-docked RFS AI assistant unless the PM changes the design. Keep authorization and view-only Reports behavior intact. Check responsive layout, keyboard access, loading/error/empty states, and relevant accessibility basics. Handoff in under 250 words: task ID, role, changed files, acceptance criteria checked, commands and actual results, outstanding risks, next role, and PM decision needed. Self-check is not independent QA.
