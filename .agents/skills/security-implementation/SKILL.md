# Security implementation

Use the fresh task packet to identify the affected trust boundary and expected outcomes. Implement scoped defenses in the approved files, preserving least privilege, server-side enforcement, and safe handling of credentials and personal data. Coordinate schema, service, and chatbot contract changes with their owners.

Use synthetic fixtures or mocked permissions to check access for authorized, unauthorized, and unauthenticated actors as relevant. Verify that errors and logs omit sensitive data. Keep production access, operational changes, and independent security approval with their owners.

Return a handoff of at most 200 words with the task ID, changed files, actual checks, gaps, and next reviewer. End the specialist turn before the coordinator starts review.
