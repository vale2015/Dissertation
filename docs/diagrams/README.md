# RFS diagrams

Open the [offline gallery](index.html) for visual previews or use the catalogue below. Each diagram has a zoomable SVG and an editable, uncompressed diagrams.net file. Open a .drawio file in diagrams.net Desktop to edit its labels, shapes and connectors. After editing, export the drawing as SVG with text enabled and replace its paired SVG.

The architecture and sequence diagrams describe the application code reviewed at **bd13533** on 24 November 2026. Seven additional agentic development diagrams document the delivery workflow published at **a272406** on 23 November 2026. The linked role registry and workflow instructions identify the configured routes. The research boards preserve the original design assumptions. The February–June Gantt chart records planned dates. For release and acceptance evidence, see the [project tracker](../product/IMPROVEMENT_TRACKER.md).

## Source inventory

19 original images contained 26 subjects. Nine architecture images and eight sequence images each contained one main diagram. The Gantt chart contained one project schedule. The composite Figma board contained eight research subjects alongside screen mockups and wireframes. The original composite preserves those screen designs. Its dashboard/chart thumbnails illustrate the prototype UI. The notebooks contained no embedded image outputs, and the Word files contained no project diagrams.

The [originals folder](originals/) preserves all 19 images and 15 original backups, including both database backup variants. Its [SHA-256 manifest](originals/SHA256SUMS) identifies every original by path and byte digest. To find a former location, prepend **Additional Documentation/** to the path in the manifest. In the archive, prepend **docs/diagrams/originals/** instead.

## Reading the archive

The architecture backups correspond to development, database (two variants), frontend, communication, ML, security, system and use cases. Six sequence backups cover booking creation, closure handling, labour cost, reservation forecasting, staff forecasting and login. The originals also include a backend architecture export and the logout and staffing-rules exports.

The ERD backup named **.$erd_restaurant_forecasting1.drawio.bkp** used CRLF line endings in the workspace. The archive preserves its pre-move byte digest. The archive’s local Git attributes keep original bytes intact on checkout.
